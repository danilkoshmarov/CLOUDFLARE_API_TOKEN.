# PANACEA SKIN

Личный локальный трекер ухода и наблюдения за состоянием кожи.

## Возможности

- Обзор ежедневного ухода и недельное расписание.
- Косметичка с редактированием средств.
- Дневник состояния кожи, заметки и фотографии.
- Карта лица: отдельный учёт воспалений по зонам.
- Календарь ежедневных наблюдений.
- Сравнение фотографий по датам с наложением «раньше / позже».
- Быстрое заполнение на основе предыдущей записи.
- Учёт сна, стресса, питания и других факторов.
- Отметки использованных средств и субъективной реакции кожи.
- Аналитика записей и сопоставление факторов с динамикой.
- Экспорт и восстановление резервной копии.
- PWA: установка на главный экран и базовая офлайн-работа.

## Запуск

Открой `index.html` или опубликуй репозиторий через GitHub Pages.

## Хранение данных и приватность

Дневник и настройки сохраняются локально в браузере через `localStorage`. Фотографии хранятся в IndexedDB на текущем устройстве. Данные не отправляются на сервер и автоматически не синхронизируются между устройствами. Экспорт создаёт JSON-резервную копию, включая фотографии. Перед очисткой данных браузера или сменой устройства сделай резервную копию.

## PWA

Сайт использует `manifest.webmanifest` и `service-worker.js`. На iPhone открой опубликованный сайт в Safari → «Поделиться» → «На экран Домой». Для офлайн-режима сначала открой сайт с интернетом, чтобы браузер сохранил файлы приложения.

## Важно

Это дневник наблюдений, а не медицинский диагностический инструмент. Сравнение сна, стресса и средств показывает только совпадения в записях и не доказывает причинно-следственную связь. Проверяй инструкции и составы средств; не применяй два кислотных продукта в один вечер.
