# PANACEA SKIN

Личный трекер ухода за кожей: ежедневные шаги, недельный график, косметичка и дневник наблюдений.

## Запуск
Откройте `index.html` или опубликуйте репозиторий через GitHub Pages.

## Хранение данных
Данные сохраняются локально в браузере через localStorage. Фотографии хранятся в записях браузера и не отправляются на сервер. Экспорт создаёт JSON-резервную копию, включая добавленные фотографии. Очистка данных браузера или потеря устройства может привести к потере данных — периодически экспортируйте резервную копию.

Это трекер, а не медицинская рекомендация. Проверяйте инструкции и составы средств; не применяйте два кислотных продукта в один вечер.
